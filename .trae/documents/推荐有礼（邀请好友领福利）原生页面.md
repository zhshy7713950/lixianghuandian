## 具体实现方案
### 1) 新增原生 Fragment（推荐有礼页）
- 新增 `FgtRecommendGift.kt`（放在 `com.ruimeng.things.me` 相关目录），继承项目现用的 `BaseBackFragment/FgtBase` 体系，使用 `QMUITopBar`。
- 初始化 UI：
  - `initTopbar(topbar, "推荐有礼")`，并把 topbar 背景改为 `#D83D3E`、标题色白色。
  - 右侧问号：`topbar.addRightImageButton(R.drawable.ic_question_white, ...)`
  - 问号点击：`AtyWeb2.start("规则说明", "http://xianglilai.scxll.cn/appH5/newClientRewardRule.html")`
- 页面数据加载：
  - 在 `onLazyInitView/onSupportVisible` 触发一次 `http { url = "/apiv6/distribute/shareqrcode" }`
  - 如接口需要 userId，我会按现有项目习惯同时带上 `params["user_id"] = userinfo.id`（userinfo 通过 `InfoViewModel.getDefault().userInfo` 获取）。
  - `onSuccess` 解析 JSON → `recmCode` 赋值到邀请码 TextView；`qrcodeUrl` 处理为可用 https URL 后用 `loadImg` 加载到二维码 ImageView。
  - https 拼接策略：
    - `qrcodeUrl` 以 `//` 开头：用 `https:${qrcodeUrl}`
    - 以 `http` 开头：原样使用
    - 其它：用 `https://${qrcodeUrl}`

### 2) 新增布局（固定头 + 可滚动内容 + 固定底图）
- 新增布局：`app/src/main/me/res/layout/fgt_recommend_gift.xml`
- Root 用 `ConstraintLayout`：
  - 顶部 `QMUITopBar` 固定
  - 大标题 TextView 固定在 topbar 下方（marginTop=30dp）
  - 底部 ImageView 贴底固定（src=`@drawable/image_invite_friend_bg`）
  - 中间 `NestedScrollView`：只让两个卡片区域滚动；设置 bottom padding 避免被底图/手势条遮挡
